A one-line museum label from the year 3000: birthday candles, small fires stuck in a cake and blown out while singing, which future scholars believe aged the eater by one year. The entry is a single line of 140 characters, written as the deadpan label a museum in the year 3000 puts beside an ordinary object from today.

## Run it

```sh
python3 main.py
```
